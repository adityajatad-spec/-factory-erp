# Factory discovery documents

> **Factory discovery is deferred because the current build is a surprise prototype. These documents will be used later for real-world validation and factory-specific configuration.**

- **Status:** deferred. Nothing in this folder blocks development.
- **Data in the meantime:** the prototype runs on clearly labelled synthetic demo data (`apps/core/src/seed/demo-data.ts`).
- **Workflows:** every workflow in the code is a provisional, generic assumption. None is a confirmed fact about any real factory.

| File | Purpose |
|---|---|
| [`factory-discovery-pack.md`](factory-discovery-pack.md) / `.pdf` | A printable on-site pack: the locking-facts sheet, a prioritized document checklist and the visit plan |
| [`factory-discovery-questionnaire.md`](factory-discovery-questionnaire.md) | The full question bank (about 150 questions, with IDs) |
| [`data-collection-checklist.md`](data-collection-checklist.md) | Detailed document and data checklist, with data-handling rules |

When discovery happens, its findings will replace the provisional assumptions and drive factory-specific configuration. Examples:
- invoice templates and numbering
- whether invoices or dispatches move stock
- units and conversions
- roles and approval thresholds
- e-invoicing applicability
- CA validation of the GST engine
